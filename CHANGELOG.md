# Changelog

## 1.0.0-beta — 2026-10-10

First public beta, displayed as **Beta v1**.

- Guided setup, saved preferences, empty workspace, and offline help.
- Multi-provider accounts, manual usage windows, reset countdowns, subscriptions, and trials.
- Account recommendations, calendar, activity, themes, and JSON backups.
- Optional Google Drive web/PWA sync with conflict review and recovery.
- Windows installer/portable builds and a development-signed Android APK.
- macOS/iOS source projects, build workflow, and GitHub publishing documentation.

Earlier local builds used internal 1.x versions. This tag starts the public beta series, preserving storage keys and incrementing native build identifiers. Native Google OAuth, Apple distribution, and automatic provider usage collection remain pending.
