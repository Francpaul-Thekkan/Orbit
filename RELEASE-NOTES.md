Orbit Beta v1

Track Claude, ChatGPT, Codex, Gemini, and other AI accounts in one offline workspace. Record usage limits, reset times, trials, and subscriptions, then see which account to use next.

Downloads: Windows x64 installer and portable EXEs, plus an Android debug APK.

Usage is entered manually. Optional Google Drive sync works in the web app after OAuth setup. Windows builds are unsigned; the Android APK is development-signed and has not yet been tested on a physical device.
